# Leyi Sheng's Personal Website

[leyisheng.github.io](https://leyisheng.github.io)

Academic website built with [al-folio](https://github.com/alshedivat/al-folio), pinned to the v0.16.3 template release.

## Local preview

```bash
docker compose up
```

Then open <http://localhost:8080>.

## Deployment

Pushing to `master` or `main` runs the included GitHub Actions workflow and publishes the built site to the `gh-pages` branch. Configure GitHub Pages to deploy from that branch.
